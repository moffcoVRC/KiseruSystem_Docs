# VRでの煙管の使い方

懐から道具を取り出し、ゆっくりと一服の支度をします。ここでは**右手持ち**で説明します。左手持ちの方は、左右を読み替えてください。

手を使わない場合は、メニューから始める[「今すぐ一服」](./instant-smoking.md)をご利用ください。

VRChatで撮影した写真と動画のコマで、アバターの所作を紹介します。手元を詳しく見るには、写真を選んで拡大してください。

## 1. 煙管と煙草入れを取り出す {#一--懐から取り出す}

初期設定はOFFです。Expression Menuの**煙管 → 操作 ON / OFF**をONにします。

導入時に選んだ持ち手（ここでは右手）で懐の判定へ触れると、煙管と煙草入れが手元に現れます。取り出したら、手を懐から離します。ONにしただけでは煙管は表示されません。

<div className="ritual-sequence">
  <RitualPhoto shot="chest-before" square alt="道具を持っていない右手が胸元にある">右手を懐へ運びます。</RitualPhoto>
  <RitualPhoto shot="chest-after" square alt="胸元で右手に煙管と茶色い煙草入れが現れたところ">煙管と煙草入れが一緒に現れます。</RitualPhoto>
  <RitualPhoto shot="retrieved" square alt="右手を懐から引き、煙草入れの後ろに煙管の軸と火皿が見える">道具を持った手を懐から離します。</RitualPhoto>
</div>

:::note ONにした時点で手が判定の中にある場合
そのままでは取り出し待ちになります。ONにした後、**一度手を判定の外へ完全に離してから、もう一度触れてください**。

**判定を大きく設定している場合は、少し離しただけでは判定内に残ることがあります。** 懐から十分に手を離し、判定の外へ出してから触り直してください。
:::

反応しない場合は[ON後の取り出し確認](./help.md#retrieval)をご覧ください。

## 2. 火皿に煙草を詰める {#二--煙草を詰める}

1. 煙管の吸い口を口へ近づけ、くわえます。
2. 右手の煙草入れに左手を添えると、蓋が開きます。
3. 開いたケースへ指を入れ、煙草玉を取り出します。
4. 指先の煙草玉を火皿へ載せます。

<div className="ritual-sequence">
  <RitualPhoto shot="case-open" square alt="右手で持つ煙草入れの蓋が開き、左手の指が近づく">開いた煙草入れへ指を入れます。</RitualPhoto>
  <RitualPhoto shot="tobacco-fingers" square alt="煙草玉が左手の指先に載り、その先に火皿が見える">指先の煙草玉を火皿へ運びます。</RitualPhoto>
  <RitualPhoto shot="tobacco-bowl" square alt="煙管をくわえ、左手の指を火皿のすぐ下に添えたところ">火皿のくぼみに煙草玉を載せます。</RitualPhoto>
</div>

蓋は煙草玉を取り出してから**1秒後**に閉じます。最初から指がケースの中にある場合は、一度離してから入れ直してください。

<div className="ritual-sequence">
  <RitualPhoto shot="side-tobacco" alt="横から見たアバター。指先の煙草玉をくわえた煙管の火皿の下まで運んでいる">横から：指先の煙草玉を火皿へ運びます。</RitualPhoto>
  <RitualPhoto shot="view-filled" alt="本人視点。金色の火皿の縁から黒っぽい煙草玉がのぞき、その横に指先が見える">本人視点：火皿の縁から煙草玉が見えれば、詰め終わりです。</RitualPhoto>
</div>

**煙管をくわえたまま、煙草入れを懐へ戻します。** ここで右手の道具がマッチ箱に切り替わります。

<div className="ritual-sequence">
  <RitualPhoto shot="case-at-chest" alt="右手に閉じた煙草入れを持ち、懐へ戻す前の様子">煙草入れを懐へ。</RitualPhoto>
  <RitualPhoto shot="box-in-hand" alt="同じ手に明るい色のマッチ箱が現れたところ">右手にマッチ箱が現れます。</RitualPhoto>
</div>

## 3. マッチを擦って火皿に火をつける {#三--マッチを擦り火を入れる}

1. 左手をマッチ箱へ重ね、マッチを取り出します。
2. 一度手を離し、頭薬をすり面の片端に当て、反対の端へ向けて擦ります。

猫の絵がある面の脇に、長く細いすり面が2つあります。どちらの面でも、両方向に擦れます。

<div className="ritual-sequence">
  <RitualPhoto shot="match-apart" alt="左手のマッチと右手の箱のあいだに隙間がある">取り出したら、まずマッチを箱から離します。</RitualPhoto>
  <RitualPhoto shot="match-strike" alt="マッチの頭薬が猫の絵の横にある細い側面に当たる">頭薬を箱の側面に当て、すり面に沿って擦ります。</RitualPhoto>
  <RitualPhoto shot="match-spark" alt="猫の絵のあるマッチ箱の脇で、頭薬に橙色の炎が上がる">マッチの先に火がつきます。</RitualPhoto>
</div>

燃えている先端を火皿の煙草玉に近づけます。煙管に火が移ると、約1秒後にマッチの火が消え、マッチも消えます。

マッチをどこへ運ぶか迷ったら、[本人視点と横から見た火皿の写真](./vr-check.md#bowl-view)を見比べてください。

<div className="ritual-sequence">
  <RitualPhoto shot="match-lit" alt="火のついたマッチが箱を離れて口元へ向かう">火を皿へ運びます。</RitualPhoto>
  <RitualPhoto shot="match-at-bowl" alt="マッチの炎と火皿に載った煙草玉が重なる">炎を煙草玉へ寄せます。</RitualPhoto>
  <RitualPhoto shot="bowl-glowing" alt="マッチが離れ、煙草玉が赤く光っている">煙草玉が赤くなれば点火できています。</RitualPhoto>
</div>

点火後は**マッチ箱だけを懐へ収納**できます。既に懐へ触れていた場合は、手を一度離してから戻してください。

## 4. 煙管を吸う {#四--煙をくゆらす}

口にくわえたまま、**右手を煙管から離してFistに握る**と吸い、口から煙を出します。握り直すたびに吸えます。

燃焼時間は**約4分**です。その間の吸引回数に制限はありません。吸っている間は火皿からの副流煙の新規生成が止まり、既に立ちのぼった煙は残ります。

煙管に手を添えると、口を支点に角度を動かせます。**持ち手を開いて、煙管の軸の「添え手の判定位置」へ手のひらを重ねてからFist**にすると、口から手へ取り戻します。火皿や吸い口に触れる必要はありません。

<div className="ritual-sequence">
  <RitualPhoto shot="hand-to-stem" alt="口にくわえた煙管の軸へ下から持ち手を近づける">取り戻すときは、手を開いて軸に添えてから握ります。</RitualPhoto>
  <RitualPhoto shot="pipe-in-hand" alt="煙管の吸い口が口から離れ、右手に煙管が移ったところ">吸い口が口を離れ、煙管が手に戻ります。</RitualPhoto>
  <RitualPhoto shot="exhale" alt="右手に煙管を持ち、口元から白い煙を吐くアバター">手に持ったままでも、握り直すと煙を吐けます。</RitualPhoto>
</div>

手を重ねる場所は[添え手の判定位置の図](./help.md#holding)で確認できます。

点火中なら、口から離した時に一度煙を吐きます。手持ちのままでも、持ち手を開いてからFistに握り直すと吐煙できます。握り続けても繰り返さず、反対の手のFistは使いません。手持ちの吐煙中は副流煙も立ち続けます。

| したいこと | 持ち手の操作 |
| --- | --- |
| 吸う | 口にくわえ、手を煙管から離してFist |
| 添えて角度を変える | 口にくわえた煙管へ手を添える |
| 手へ取り戻す | 開いた持ち手を軸の判定へ重ねてFist |
| 手持ちで吐煙する | 点火中に持ち手を開き、Fistに握り直す |

## 5. 火を消して煙管をしまう {#五--火を落とし仕舞う}

1. 火のついた煙管を口から持ち手に戻し、**火皿の穴を斜め下に向けます**。
2. 灰皿の縁を軽くたたくように、**手首を下へ振って、元の角度へ戻します**。火皿から「キン」と鳴れば1回です。空中でできます。
3. 同じ動きを続けて**合計3回**。3回目の金属音とともに灰が落ち、火皿の赤い光が消えます。

灰が落ちたら、持ち手を懐から一度離し、**煙管を持ったまま握って（Fist）懐へ戻す**と収納できます。

点火前の煙草玉だけを捨てるときは、火皿を下に向けたまま約0.35秒待ちます。

:::tip 続けてもう一服するとき
燃焼中は、収納済みマッチ箱の再取り出しと、新しいマッチの取り出しが止まります。火種を捨てた後や燃焼終了後は、持ち手を開き、懐から一度離して、もう一度約0.25秒触れると煙草入れが出ます。煙管をくわえたまま次の煙草を詰められ、Resetは不要です。
:::

## 撮影中に燃焼時間を止める {#撮影の間一服を保つ}

**煙管 → 撮影・設定 → 喫煙を維持**をONにすると、燃焼の残り時間を一時停止します。OFFにすると残り時間から再開します。煙や吐煙は継続します。撮影中も手首を3回振って消火できます。操作OFFとResetも使え、Resetで維持設定を解除できます。

## はじめからやり直す

メニューの**Reset**、または**OFF → ON**で初期状態へ戻します。

起動ジェスチャーも使う場合は、煙管を持つ側の手を懐で**ThumbsUp（Gesture 7）**にします。
