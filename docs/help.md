# よくあるトラブルと対処法

まず、うまくいかない**操作と、その直前の状態**を確認します。位置の調整なのか、所作の順序なのかを、ひとつずつ確かめてください。

## 触れても道具が反応しない {#contacts}

### ONにしても煙管が見えない {#retrieval}

初期設定はOFFです。ONだけでは表示されません。次の順に確かめてください。

1. **煙管 → 操作 ON / OFF**をONにします。
2. 導入時に選んだ**持ち手**を、懐の判定から完全に離します。
3. その手でもう一度懐に触れます。反対の手は取り出しに使いません。

ONにした時点で手が取り出し判定の中にあると、取り出し待ちになります。ONにした後、**一度手を判定の外へ完全に離してから、もう一度触れてください**。

**判定を大きく設定している場合は、少し離しただけでは判定内に残ることがあります。** 懐から十分に手を離し、判定の外へ出してから触り直してください。手側にも判定の大きさがあるので、手の中心が外へ出ただけでは重なりが残る場合があります。

更新後のアバターで起きる場合は、[パッケージ更新後の導入更新・再アップロード](./install.md#update)も確認します。これでも取り出せない場合は、判定をさらに大きくする前に、持ち手・判定位置・ONの状態を確認し、操作手順と診断ログをお知らせください。

### 煙草玉やマッチを取り出せない

既に指や手が判定の内側にある場合は、**一度離してから触り直します**。ケースの開閉と、指の取付位置・判定位置も確認してください。

燃焼中は新しいマッチを取り出せません。火皿が空になったら、持ち手を懐から一度離して触り直すと、煙草入れから次の一服を始められます。

### 口にくわえづらい、箱が開きづらい

プレビューの判定表示で、口元・箱・指先の位置を確認します。見た目だけでなく、手を近づけたときに接触判定へ届く配置に整えてください。[配置調整](./placement.md)へ戻れます。

## 配置や持ち方が合わない {#placement}

### 仮面やアクセサリーで口元が見えない

ヒエラルキーで該当するアクセサリーを選び、Inspector上部のGameObjectのチェックを一時的に外します。配置画面の**表示を更新**を押すと、編集中の配置を保って表示を読み直します。

調整を終えたら、アクセサリーを元の表示状態へ戻し、もう一度**表示を更新**してください。非表示のまま保存・アップロードしないよう確認します。

### 衣装だけ元の姿勢のままになる

素体と衣装で同じボーンを使っているか、MA Merge Armatureなどで追従させる構成かを確認します。共有ボーンとMAの構成はプレビューの確認対象ですが、別の仕組みで動く衣装は個別確認が必要です。衣装のボーンを削除して対処せず、アバター・衣装の製品名と構成を添えてご連絡ください。

### 火皿の受け入れ判定が見た目と合わない

**火皿の火種**で、通常プレビューに表示されるオレンジ色の判定中心も火皿の中に合わせます。火種を載せる判定と点火判定が一緒に追従します。**Merge後の判定を確認**では、現在の調整値を複製へ導入した後の判定を緑色で確認できます。

確認後に**アバターの導入を更新…**を行ってください。Merge後の確認画面は、元のアバターを更新するボタンではありません。

### 自分からだけ火皿が見えない

[火皿の見え方を本人視点と横から比べる](./vr-check.md#bowl-view)で、くわえた直後と、燃えているマッチを運ぶ場面を確認できます。

他の人からも見えないのか、自分の一人称視点だけで見えないのかを分けてご連絡ください。カリング距離だけで原因は断定できません。使用したアバター、口元の配置、鏡・他の人からの見え方が調査の手掛かりになります。


### 手首をひねらないと吸い口が口へ向かない

「煙管の持ち位置」で**手持ちのまま口元で向きを確認**を使います。口元へ運ぶポーズで、Local軸の回転と位置を調整してください。

### マッチを擦るとコントローラーがぶつかる

マッチ箱とマッチの取付ボーンを見直し、指先や手の外側へ余裕を取ります。煙草入れも手のひらへ寄せすぎないよう確認します。調整後は実際のVRで確かめてください。

Indexをお使いの場合は、[所作用の手の形を登録する推奨設定](hand-poses.md#index-controller)もご確認ください。指の形を決めた後に、実機がぶつからないようマッチと箱の配置を調整します。

### プレビューのポーズがアバターへ反映されない

確認ポーズは配置を見るためのものです。導入されるのは、取付ボーンを基準にしたパーツの位置・角度です。ポーズ自体をアバターへ書き込む機能ではありません。

## 吸う・取り戻す・収納する {#holding}

### Fistにしても吸えない、手に戻ってしまう

**口にくわえ、持ち手を煙管から離した状態**でFistにします。煙管へ触れていると、手へ取り戻す操作になります。

### どこを握れば手へ取り戻せるか分からない

煙管を持つ側の手を開き、**軸の「添え手の判定位置」へ手のひらを重ねてからFist**にします。右手持ちなら右手、左手持ちなら左手です。火皿や吸い口を握る必要はありません。

![口から手へ取り戻す3つの手順](/img/reacquire-guide.svg)

判定の位置はアバターごとに調整できます。配置画面の**添え手の判定位置 → 取り戻す判定を表示して寄る**で確認してください。図のオレンジ色は説明用で、VR内には表示されません。

### 手首を振っても火が消えない {#extinguish}

火のついた煙管を持ち手に戻し、火皿の穴を斜め下に向けます。手首を振ったときに「キン」と鳴れば1回です。次の音が鳴りづらいときは、手首を少し起こしてからもう一度振ってください。腕を上下させるだけでは火皿の角度は変わりません。

途中で長く休んだり、煙管を口に戻したりすると1回目からになります。[消火の手順と手首の動き（GIF）](./ritual.md#五--火を落とし仕舞う)でリズムを確認できます。旧版をお使いの場合は、最新版をインポートして[導入の更新と再アップロード](./install.md#update)を行ってください。

### 煙管を懐にしまえない {#煙管を懐へ仕舞えない}

燃焼中は、まず[手首を3回振って消火](./ritual.md#五--火を落とし仕舞う)します。灰が落ちたら、持ち手を懐から一度離し、煙管を持ったままFistにして懐へ戻します。

### 燃焼中、収納したマッチ箱を取り出せない

吸っている途中の誤操作を防ぐための動作です。火皿が空になったら、持ち手を開き、懐から一度離して、もう一度約0.25秒触れると煙草入れが出ます。Resetは不要です。

### 撮影中に火を消したくない

**煙管 → 撮影・設定 → 喫煙を維持**をONにすると、残りの燃焼時間を止められます。OFFにすると残り時間から再開します。煙と吐煙は続き、手首を3回振る消火や操作OFF・Resetも使えます。「今すぐ一服」でも時間維持が使えます。

### 状態が分からなくなった

Expression Menuの**Reset**、または**OFF → ON**で初期状態へ戻してから、[VRでの煙管の使い方](./ritual.md)を順に試します。

## 導入時にエラーが出る {#setup-errors}

エラー時に表示されるオレンジ色の**診断ログを作成して保存**を利用してください。依存パッケージや必要アセット、パラメーターの状態などを調べられます。

コンパイルエラーで画面が開けない場合も含め、[診断ログとエラーの伝え方](./diagnostics.md)に手順をまとめています。
