# アバターへの導入と保存

配置が整ったら、**アバターへの導入とSceneの保存**を行います。

配置から順に確認する方は、[画面を見ながら導入する](./editor-guide.mdx)をお使いください。

## 1. 診断を確認してアバターへ反映する {#apply}

アバターの配置セットアップ画面で左上の表示を見て、下のタブを選んでください。画像を押すと、そのボタンがある画面全体を確認できます。

<Tabs>
<TabItem value="new" label="初めて導入する">

**① 配置画面から最終診断を開く**  
左上に「未導入」と表示されます。調整を終えたら、画面下部の **① 導入前の診断を確認** を押します。隣の **次へ** は、次のパーツの配置を調整するときに使います。

<SetupCapture shot="fresh-review" detail="button" width={381} height={55} alt="初回の配置画面下部。「① 導入前の診断を確認」は「次へ」の左隣" />

**対象・持ち手・容量を確かめる**  
画面右側に診断が表示されます。「対象」が導入したいアバターか、「煙管を持つ手」が選んだ側か、導入後の同期パラメーターが容量内かを確認します。調整し直すときは **パーツ設定へ戻る** を押します。

<SetupCapture shot="fresh-confirm" detail="review" width={302} height={211} alt="最終診断の右側。対象、煙管を持つ手、導入後の容量と診断結果" />

**② 新規導入を確定する**  
右下の **② このアバターに新規導入** を押すと、現在の配置で煙管一式を生成します。

<SetupCapture shot="fresh-confirm" detail="button" width={238} height={55} alt="最終診断の右下にある「② このアバターに新規導入」" />

</TabItem>
<TabItem value="existing" label="導入済みを更新する">

**① いまの調整で更新前の診断を開く**  
配置や指の形などを直したら、右下の **① 更新前の診断を確認** を押します。

<SetupCapture shot="installed" detail="button" width={238} height={55} alt="導入済みアバターの配置画面右下。「① 更新前の診断を確認」" />

**置き換え後の見積もりを読む**  
右側で対象と持ち手を確認します。画像は1.00の診断例です。このアバターを1.01に更新すると、使用中95 bitのうち煙管の20 bitが22 bitに替わり、合計は97 bitになります。

<SetupCapture shot="update-confirm" detail="review" width={302} height={210} alt="更新の最終診断。現在の使用量、置換分、今回の煙管の使用量と合計が表示される" />

**② 更新を確定する**  
右下の **② このアバターの導入を更新** を押して、編集中の設定を反映します。

<SetupCapture shot="update-confirm" detail="button" width={238} height={55} alt="最終診断の右下にある「② このアバターの導入を更新」" />

</TabItem>
</Tabs>

**反映後の目印**は、左上の緑色の **煙管システム 導入済み** とバージョンです。右下から導入・更新した後は、続けてSceneを保存してください。

<SetupCapture shot="installed" detail="status" width={353} height={59} alt="アバターへの導入後の画面。左上に緑色で「煙管システム 導入済み」と導入したバージョンが表示される" />

必要なPrefab・FX・Expression Menu・パラメーターが生成され、Modular Avatarを通じてアバターへ組み込まれます。元のアバターのFXやメニューのアセットは保持します。

## 2. Sceneを保存する

Unityで**Sceneを保存**してください。導入ボタンを押す操作と、Sceneの保存は別です。

:::warning 生成したデータを残してください
`Assets/KiseruUserSettings/`には、衣装用プリセットと生成済みの導入データが入ります。導入後にこのフォルダを削除しないでください。Sceneやアバターと一緒にバックアップします。
:::

## 3. VRChatへアップロードする

VRChat SDKから、通常の手順でBuild / Uploadします。煙管の導入画面が自動でアップロードすることはありません。

アップロード後は、[VRでの確認項目](./vr-check.md)に沿って所作を確かめます。

## 「配置だけSceneへ反映」との違い

| 操作 | 役割 |
| --- | --- |
| ② このアバターに新規導入 | 初回の組み込み。必要なPrefab・FX・メニュー・パラメーターを生成します |
| ② このアバターの導入を更新 | 導入済みアバターへ、配置や動作の更新を反映します |
| 配置だけSceneへ反映 | 既存の煙管リグの配置を反映します。初回導入やFX・メニューの生成ではありません |
| 保存 ▾ → 衣装用プリセットを新規保存… | 他の衣装へ持ち越すため、配置を任意で保存します |
| Sceneの保存 | UnityのSceneとして、導入・調整した状態を残します |

持ち手を左右で切り替えた場合は、**① 更新前の診断を確認 → ② このアバターの導入を更新**から反映してください。

## 持ち方を後から変える

導入済みのアバターを選び直すと、現在の配置から再編集できます。指の形や道具の位置は、手首補正がOFFのままでも調整できます。煙管を持つ間の手首の返しも変えたい方は、[手首と前腕の補正](./wrist.mdx)を設定してから、上の「導入済みを更新する」手順へ戻ってください。

衣装違いへ持ち越す場合は、[衣装用プリセットの保存と読み込み](./presets.md)をご覧ください。


## 配布パッケージを更新する {#update}

1. 作業中の調整を衣装用プリセットへ記録し、必要なSceneを保存します。配置画面を閉じ、プロジェクトをバックアップします。
2. 新しいUnitypackageを**全項目インポート**します。C#・asmdef・DLLを除外しないでください。小さな互換C#ファイルも保存データの参照に必要です。利用者が.NETやVisual Studioを追加する必要はありません。
3. インポートとコンパイルが終わったら対象アバターを指定し、配置・手の形・モデル選択を確認します。`Assets/KiseruUserSettings/`と対象Sceneは削除しません。
4. **① 更新前の診断を確認 → ② このアバターの導入を更新**で反映します。未対応の補助ボーンの案内が出た場合は、案内された補正をOFFにして再診断します。
5. **Scene保存 → VRChatへ再アップロード → VRで確認**を行います。

パッケージのインポートだけでは、導入済みアバターの動作データは更新されません。Editor表示だけの変更で更新不要と明記された版を除き、上記手順で反映してください。DLL版から旧ソース版へ戻す場合は、上書きせず更新前のバックアップを使用します。
