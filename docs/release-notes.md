# バージョンと配布内容

## 煙管システム 1.01

Windows PC向けのVRChatアバターで使用できます。煙管と長煙管、煙草入れ、煙草玉、マッチ箱、火花・煙・音を同梱しています。火を消すときは、手に戻した煙管を下向きにして手首を軽く3回振ります。[灰を落として煙管をしまう手順](./ritual.md#五--火を落とし仕舞う)を確認できます。

Unityの[配置セットアップ](./editor-guide.mdx)で道具を左右の手に合わせ、指の形、手首の向き、前腕へ分けるひねりの量を調整できます。持ち方と衣装用の配置を保存し、後から再編集できます。

## 購入前の無料チェッカー

製品とは別にインポートできます。[導入前の準備](./getting-ready.md#preflight)で操作手順と確認項目を紹介しています。

## パッケージを更新したら

既に導入したアバターには、最後に反映した版が表示されます。[導入を更新](./install.md#update)し、Sceneを保存してVRChatへ再アップロードしてください。

## 外部アセットとライセンス

SDK・Modular Avatar・NDMF・lilToonは[準備する環境](./getting-ready.md)を参照してください。アバター本体と衣装は利用者が用意します。

コントローラーモデルはUnityの配置プレビューに使用します。MITライセンスと出典は製品の `Editor/ControllerModels/` に同梱しています。
