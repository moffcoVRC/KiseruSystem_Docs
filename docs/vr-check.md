# VRで持ち方と操作を確認する

プレビューで整えた配置を、実際の持ち方で確かめます。**コントローラーをぶつけず、一連の所作がつながるか**を見てください。

## Unityで判定を確かめる

配置セットアップ下部の **「配置をPlay Modeで確認」** を押すとPlay Modeに入り、Scene Viewで全道具と判定を一時表示します。別の確認ウィンドウを操作する必要はありません。導入済みの配置が対象なので、調整中の値は先に導入・更新で反映してください。手を操作して所作を再現する機能ではありません。

煙管・煙草入れ・火種・マッチ箱・マッチと、半透明の判定範囲、その用途名を見渡せます。水色は送信側、橙は受信側です。GestureManagerと併用し、実際に接触している位置と表示位置が一致する判定は緑になります。

Scene View上部の **「手持ち／口元」** で煙管の配置を見比べ、Unity標準の回転・ズームで見たいところへ寄ってください。確認後は **「確認を終了」**、配置画面の **「Play Modeを終了して配置調整へ戻る」** またはUnityのPlay停止で戻ります。

表示用コピーに接触判定や音はありません。元の調整値やパラメーターは変更せず、Sceneも自動保存しません。煙管の手持ち／口元の切り替えは配置確認用の表示で、実際の所作を切り替えるものではありません。

:::note 導入済みの方へ
この表示機能だけを使うための再アップロードは不要です。配置や動作を変更した場合は、[導入の更新と再アップロード](./install.md#update)を行ってください。
:::

## 道具を運ぶ

- 持ち手を懐から離してメニューをONにし、その手で触れると煙管と煙草入れを取り出せる。
- 手が判定内にある状態でONにした場合も、完全に離してから触り直すと取り出せる。
- 判定を大きくした場合も、十分に手を離して判定の外へ出せる。
- 手首を無理にひねらず、吸い口を口元へ運べる。
- 煙草入れを開き、指先で火種を取り出して火皿へ載せられる。
- 煙草入れを懐へ戻すと、マッチ箱に切り替わる。

## 火を入れる

- 反対の手を添えるとマッチ箱が開き、マッチを取り出せる。
- コントローラーがぶつからずに、マッチの頭薬をすり面へ運べる。
- 点火した先端を火皿へ近づけられる。
- 煙管への点火後、約1秒でマッチが消え、箱だけを懐へ戻せる。

## 煙管を吸ってからしまう {#一服して仕舞う}

- 口にくわえ、持ち手を煙管から離してFistにすると吸える。
- 手を添えたときに角度を変えられ、触れてFistにすると手へ戻せる。
- 燃焼中に懐へ手が入っても、煙管が収納されたり、収納済みの箱が出直したりしない。
- 火のついた煙管を手に持ち、火皿の穴を斜め下に向けて手首を軽く振り戻す。1回ごとに「キン」と鳴り、3回目で灰が落ちて火皿の赤い光が消える。[手首の動きを見る](./ritual.md#五--火を落とし仕舞う)
- 消火後、懐から手を一度離し、手持ちでFistにして戻すと仕舞える。

## 配置が合わないときの調整方法 {#合わなければひとつずつ整える}

扱いづらかった所作を覚えておき、Unityでそのパーツの位置や取付ボーンを調整します。**配置を更新 → Sceneを保存 → 再アップロード → VRで確認**の順に進めてください。

動作の詳細は[VRでの煙管の使い方](./ritual.md)、反応しない場合は[困ったとき](./help.md)をご覧ください。

手首補正を入れた方は、煙管を持ったまま[VRで手首補正のON／OFFを比べる](./wrist.mdx#vr)手順で、手と袖の動きも確認してください。

:::note プレビューと実機の違い
画面上の配置や診断だけでは、実際の握り方や機種ごとの操作感までは確定できません。別プロジェクトへの新規インポート、Build / Upload、VRChatでの最終確認も、使用する環境で行ってください。
:::
