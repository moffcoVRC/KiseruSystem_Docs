# 衣装用プリセットの保存と読み込み

一度整えた持ち方は、**衣装用プリセット**に残せます。同じ素体の衣装違いへ持ち越し、胸元や小物の位置を仕上げてください。

## 今のアバターを再編集する

1. 配置セットアップで、導入済みアバターを指定します。
2. 現在の配置をもとに、必要なパーツを調整します。
3. **① 更新前の診断を確認 → ② このアバターの導入を更新**から反映します。
4. Sceneを保存します。

同じアバターを再編集するだけなら、衣装用プリセットの作成は必須ではありません。

## 持ち方をプリセットに残す

**保存 ▾ → 衣装用プリセットを新規保存…**を押して保存します。名前は「普段着・右手」「和装・左手」など、後から区別できるものにすると探しやすくなります。

標準保存先は `Assets/KiseruUserSettings/` です。

## 調整を中断して後で再開する {#一服置いて後で続きを行う}

作業を後日に持ち越す場合も、**保存 ▾ → 衣装用プリセットを新規保存…**を使います。ウィンドウを閉じた後やSceneを切り替えた後はアバター選択から始まり、編集中だった値は自動復元しません。持ち越したい調整は、Sceneを切り替える前に保存してください。

アバターへ未反映で、プリセットにも記録していない調整がある場合は、閉じる際に確認します。

| 選択 | 操作 |
| --- | --- |
| キャンセル（Cancel） | 編集画面へ戻ります。アバターへ反映する場合は導入・更新を行ってください。 |
| 保存（Save） | 衣装用プリセットに保存して閉じます。アバターへは反映しません。 |
| 破棄（Discard） | 今回の編集を破棄して閉じます。既存のプリセットやアバターは変更しません。 |

アバターへ反映済み、またはプリセットへ保存済みなら、そのまま閉じられます。保存先の選択をキャンセルした場合は閉じずに編集を続けられます。Scene保存は別操作です。

再開するときは対象アバターを選び、**読み込み ▾ → 保存済みプリセットを読み込む…**から読み込みます。Play Modeの往復やスクリプトのコンパイルでは、開いているウィンドウの調整を保持します。

## 別の衣装へ読み込む

1. 別の衣装のアバターを、対象アバターへ指定します。
2. 診断を行い、配置画面へ進みます。
3. **読み込み ▾ → 保存済みプリセットを読み込む…**を押します。
4. 開いた保存先フォルダからプリセットを選びます。
5. 衣装との重なりや胸元の位置を確認して調整します。
6. アバターへ導入し、Sceneを保存します。

:::note 体格が変わる場合
同じ素体の衣装違いを主な用途としています。別のアバターなど、体格・手の大きさ・ボーン軸が異なる場合は、位置と角度の再調整が必要です。
:::

## 保存先ごとの違い

| 保存先 | 残るもの |
| --- | --- |
| Scene | そのアバターに導入した状態 |
| 衣装用プリセット | 他の衣装へ持ち越す配置の設定 |
| エディタの表示設定 | プレビューの背景色など |

確認ポーズそのものは、アバターや衣装用プリセットへ書き込みません。
