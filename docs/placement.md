# 煙管と道具の配置調整

無理なく口元へ運べる持ち方、指を添えやすい箱の位置。**所作がつながる配置**を、プレビューで探します。

初めて操作する方は、[移動の矢印をつかむ](./editor-guide.mdx#move) → [回転の輪をつかむ](./editor-guide.mdx#turn) の順に、エディタ全体の画像で試してください。

## 煙管の持ち位置を見比べる {#shinano-grip}

アバターの右手を同じ角度から撮影しました。「初期配置」では煙管の持ち位置を初期値に戻し、「位置調整後」では指を開いたまま火皿の位置を合わせています。最後に手の形を反映して、指と煙管の軸がどう重なるかを確認します。

指先に付けた道具の動きは、[マッチ箱の作例](./hand-poses.md#shinano-box)で見比べられます。

## 先に、確認ポーズと視点を選ぶ

調整するパーツを左側で選び、確認ポーズを切り替えます。「両手を近づける」などのスライダーは、手の動きを確かめるためのものです。

| 視点の操作 | 入力 |
| --- | --- |
| 周囲を回り込む | Alt + 左ドラッグ |
| 視点の向きを変える | 右ドラッグ |
| 平行移動 | 中ボタンドラッグ |
| 拡大・縮小 | ホイール、または Alt + 右ドラッグ |

ギズモの軸は**Local**が初期値で、パーツ自身の向きに沿って調整できます。**Global**へ切り替えると、プレビュー空間のXYZ軸に沿って移動・回転できます。上部の「背景」で色を選び、「戻す」で初期色に戻せます。

:::note ポーズと配置は別のものです
確認ポーズや手首の傾きは、配置を確認するためのプレビューです。アバターのアニメーションとして保存されません。[持ち方編集の手首補正](./hand-poses.md#wrist)とは別の機能です。実際の持ち位置・角度は、パーツの移動・回転で調整してください。
:::

## 1. 煙管を、口元へ運ぶ

1. **煙管の持ち位置**を選びます。
2. **手持ちのまま口元で向きを確認**を使い、確認ポーズを「手持ちで口元へ」にします。
3. 口元への距離と手首の傾きを動かします。
4. 煙管を手に持ったまま、吸い口が自然に口へ向くよう、持ち位置と回転を整えます。

手首を大きくひねらなくても吸い口を近づけられるかを確認してください。次に**口にくわえる位置**を選び、**喫煙時の口元**と**点火時の口元**をそれぞれ調整します。点火時は水色の水平ガイドを目安に、吸い口を唇に合わせ、火皿を見やすい角度へ整えます。点火後は約0.5秒で喫煙姿勢へ移ります。

## 2. 懐と添え手の判定を整える

**取り出し・収納位置**を、胸元の触れやすい位置に合わせます。衣装に埋まって手を入れにくくならないかも確認します。

取り出し判定は、**触れやすさに加えて、手を十分に離して判定の外へ出せる範囲**に調整してください。手が判定の中にある状態でONにすると、一度完全に離して再接触するまで取り出し待ちになります。判定を大きくした場合は、少し離しただけでは判定内に残ることがあるため、VRでも懐から十分に手を離せるか確認してください。

**添え手の判定位置**は、口にくわえた煙管に手を添える位置です。煙管を支え、取り戻す所作で触れやすい場所に合わせます。

判定の表示を使って位置と範囲を確認します。見た目のモデルの大きさと、接触判定の範囲は別に確認してください。

## 3. 煙草入れと火種を合わせる

**煙草入れ → 指の火種 → 火皿の火種**の順に選び、取り出して火皿へ載せる動きを想像しながら整えます。

手持ちパーツは、使う側の手・指・手の配下の補助ボーンから取付先を選べます。初期配置では、煙草入れは持ち手、指の火種は反対側の親指を使います。アバターのボーン構成によっては、近い関節や手へ切り替わります。

## 4. マッチを擦れる間隔をつくる

**マッチ箱**と**マッチ**をそれぞれ選び、取付ボーン・位置・角度を調整します。初期配置では、箱は持ち手の人差し指、マッチは反対側の人差し指を使います。

「マッチを擦る」確認ポーズで両手を近づけ、頭薬を箱のすり面へ運べるかを確認します。手のひらへ寄せすぎず、指先や手の外側に余裕を取ると、調整の出発点になります。

## コントローラーと道具の間に、余裕を

コントローラー表示は**Quest 3**が初期状態です。使用機種に合わせて、Quest 3 / Quest 2 / Index / VIVE / PICO 4から選択できます。PICO 4はリングを除いた表示です。

表示寸法はアバターの手の大きさに合わせて変化します。必要に応じて位置や大きさを補正してください。コントローラー同士の近接表示は目安なので、道具との重なりも見て確認します。

:::warning 仕上げは実際のVRで
実際にVRで持ち方と配置を確認してください。コントローラーが煙管・マッチ箱・煙草入れに干渉すると、所作を行いづらい場合があります。
:::

配置が整ったら、[導入と保存](./install.md)へ進みます。

## 左右から眺め、判定も確かめる

プレビュー上部の**右側・左側**、または右上の視点ギズモを押すと、アバターの各方向から眺められます。右側・左側はアバター自身を基準にしています。Alt＋左ドラッグによる自由な周回も使えます。

**火皿の火種**の移動・回転・スケールには、火種を載せる判定と点火判定が追従します。見た目の煙草玉と判定中心を火皿の中へ合わせてください。

**火皿の火種**と**添え手の判定位置**にある**Merge後の判定を確認**は、現在の調整値でアバターの複製に導入し、MA / NDMF処理後の判定を表示します。緑が火種・点火、橙が添え手・取り戻しです。

これは静止した配置を確認する画面です。元のアバターは更新せず、接触の発火・VRの追跡・一人称の描画までは再現しません。確認を終えたら、元の配置画面で導入または更新を行ってください。


## 色と見出しで、調整する道具を選ぶ

配置メニューでは、煙管は青、懐は紫、煙草は緑、マッチは橙でカテゴリを分けています。
番号と用途名も併記するので、色だけで区別する必要はありません。
左側最下部の「会話連動」で、会話に合わせた小さな動きをONにできます。変更後は導入を更新します。
「外観モデルを選ぶ・改変」から[モデルの所在と差し替え](./models.md)へ進めます。

手の形は左下の **持ち方・手の形を作る** から編集します。[手の形を編集する](./hand-poses.md)を参照してください。
