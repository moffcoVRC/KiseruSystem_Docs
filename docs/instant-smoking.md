# 「今すぐ一服」の使い方

ひと息つきたいときは、所作を省略して。**「今すぐ一服」**を使うと、煙管を口にくわえたまま自動で一服できます。デスクトップなど、手で道具を扱えない環境にも向いています。

## メニューをONにする

Expression Menuの**煙管 → 今すぐ一服**をONにします。通常の「操作 ON / OFF」がOFFでも、そのまま始められます。

調整済みの口の位置へ煙管が装着され、煙草玉を載せた状態で点火します。煙草入れやマッチを取り出す操作は不要です。

## 自動で煙を吸う間隔 {#ゆるりと煙をくゆらす}

開始直後に一度吸い、その後は**約6秒ごと**に自動で吸います。1回の吐煙は約1.2秒です。

吸っている間は副流煙の生成が一時的に止まり、既に出ている煙は残ります。燃焼時間は、初期設定で**約4分**です。

自動モード中は手を添えたり握ったりしても持ち替えません。懐の判定に触れても、煙草入れやマッチ箱は出ません。

## 一服を終える

**今すぐ一服をOFF**にすると、火を落として収納します。「操作 ON / OFF」をOFFにするか、Resetを押しても終了できます。

燃焼時間が終わった場合も自動で消火・収納し、「今すぐ一服」をOFFに戻します。通常操作は開始前の状態へ戻ります。開始前がONならON、OFFならOFFです。通常操作を明示的にOFFにした場合とResetではOFFになります。[手首を3回振って消火する](./ritual.md#五--火を落とし仕舞う)のは、通常操作で煙管を手に持っているときです。

## 手で操作するモードに戻る {#通常の所作へ戻る}

自動モード終了後、**操作 ON / OFF**がOFFならONにします。持ち手を懐の判定から完全に離してから触れると、道具を取り出せます。続きは[VRでの煙管の使い方](./ritual.md)をご覧ください。

:::note メニューが見つからない場合
パッケージを更新した後は、配置画面の **① 更新前の診断を確認 → ② このアバターの導入を更新** を押してください。Sceneを保存し、VRChatへ再アップロードします。
:::

## 撮影中の燃焼時間を維持する

**煙管 → 撮影・設定 → 喫煙を維持**をONにすると、自動の吐煙を続けながら残りの燃焼時間を止められます。OFFで残り時間から再開します。終了したい時は「今すぐ一服」または通常操作をOFFにするか、Resetを押します。
