# 手の形を編集する

用途ごとに指の形を設定する任意機能です。手の形を設定していない用途は、アバター元来のジェスチャーを使います。

[マッチ箱を持つ人差し指を曲げてみる](./editor-guide.mdx#fingers)と、スライダーを動かす前後をエディタ全体の画面で見比べられます。

## 指の形とマッチ箱の位置を見比べる {#shinano-box}

アバターの右手の人差し指にマッチ箱を取り付けた例です。箱のすり面を合わせた後は、手の形を反映した状態でもう一度見てください。指が曲がると、すり面の向きも変わります。

## Indexコントローラーをお使いの方へ {#index-controller}

**Indexをご利用の場合は、次の3用途の手の形を登録することを推奨します。**

| 所作 | 「用途」で選ぶ項目 |
| --- | --- |
| 煙草入れから火種を取り出す | **火種をつまむ** |
| マッチ箱を持つ | **マッチ箱を持つ** |
| マッチを持って擦る | **マッチをつまむ** |

Indexでは、グリップの握り具合に応じて指が動きます。指に取り付けた火種やマッチの位置も動くため、狙った場所へ運びにくくなることがあります。また、コントローラー本体が大きく、マッチと箱を近づける際に実機同士がぶつかりやすいため、所作中の手の形を固定すると操作を安定させやすくなります。

**持ち方・手の形を作る → 用途**で上記を一つずつ選び、指を調整して**編集した手の形を所作に反映する**から保存してください。手の形を決めた後に、火種・マッチ箱・マッチの取付位置を確認します。コントローラープレビューをIndexに合わせ、箱やマッチを手のひらに寄せすぎず、実機がぶつからない間隔も確保してください。

最後に**アバターの導入を更新 → Scene保存 → 再アップロード**を行い、VRで取り出しと擦る動作を確認してください。固定されるのは設定した用途の指で、所作が終わると通常の指トラッキングへ戻ります。火種の手の形は、取り出して手に持っている間に適用されます。

## 編集して所作用に設定する

1. 配置セットアップの **持ち方・手の形を作る** を開きます。
2. **用途** を選びます。煙管・煙草入れ・火種・マッチ箱・マッチの5種類です。
3. その下の指名、またはプレビューの骨の番号を選び、付け根・中節・末節の伸ばしと左右の開きを調整します。
4. 必要なら **手を拡大** で寄り、道具とコントローラーとの位置を確認します。
5. 用途「煙管を持つ」では、同じ画面で煙管の位置・回転も調整し、**持ち方を保存して所作に反映する**から.assetを保存します。他の用途では**編集した手の形を所作に反映する**から.animを保存します。同名は更新、別名はコピーです。保存するとその用途の形が有効になります。
6. 最後に右下の **① 更新前の診断を確認 → ② このアバターの導入を更新** を実行します。初回は **① 導入前の診断を確認 → ② このアバターに新規導入** です。手の形と編集中の配置をまとめてアバターへ反映し、Sceneを保存してVRChatへ再アップロードします。

保存先の選択をキャンセルした場合や保存に失敗した場合、新たな用途は有効になりません。編集中の値は残るため、そのまま続きを調整できます。
設定済みの用途を再編集した場合も、変更は編集中の設定です。アバターへの導入更新まではSceneの所作を変更しません。

煙管を持つ手の左右設定から、各用途で使う手を自動で選びます。火種とマッチは反対の手です。
指に付けた道具は指の形に応じて移動するため、手の形と取付位置を行き来して調整してください。
指のスライダーを動かしても道具の取付位置・回転の設定値は保たれます。5つの用途すべてで、手の編集画面の「持ち位置・向き」で道具を動かせます。煙管以外の用途で保存する.animには指の形が入り、道具の配置はアバターへの導入更新で反映されます。

**切替時間（秒）** の初期値は0.2秒です。所作へ入る／元のジェスチャーへ戻る時に滑らかに切り替えます。
**この用途を元のジェスチャーに戻す** は設定済みの用途にだけ表示します。解除後も導入を更新してください。

## 保存した形・配布された形を使う

用途「煙管を持つ」では **持ち方・手の形を読み込む…**、他の用途では **所作用の手の形を読み込む…** から選びます。
持ち方の.assetは `Assets/KiseruUserSettings/HoldingStyles`、指だけの.animは `Assets/KiseruUserSettings/HandPoses` が標準保存先です。持ち方は指・煙管の取付位置と回転・手首補正を一組で保存します。**指の形だけを保存 (.anim)…** で指だけを保存することもできます。第三者の手の形は、先にUnityのAssets内へインポートしてください。

- Humanoidの指カーブを持つ **.anim** に対応します。先頭フレーム（0秒）の形だけを読み込みます。
- 両手のカーブがあれば編集中の手を使います。反対の手だけのカーブなら、指の値を左右変換します。
- 指の未記録項目は中立値になります。腕・身体・表情・オブジェクトのカーブやAnimationEventは取り込みません。
- 旧版の手の形プリセット **.asset** も読み込めます。
- Transformのボーン回転だけを記録したClipは、アバターごとの骨構成に依存するため対応していません。

読み込み後はプレビューで指と道具を確認し、用途に対応する反映ボタンから保存します。
同名保存では、既存のAnimationClipを編集中の手の形で更新し、GUIDと既存の参照を維持します。別名を指定すると元のClipを残せます。
保存したファイルと所作設定は値のコピーなので、元ファイルを後で編集しても自動更新しません。
手の形は衣装用プリセットと導入設定にも保存されます。

**Sceneの手の形から取り込む** は、表示更新時に取得したSceneの手の姿勢を読み込みます。Scene側の手を変更した時は、先に **表示を更新** を押してください。

## 手首と前腕の補正を試す {#wrist}

指と煙管の位置が決まったら、好みで手の甲の向きも調整できます。設定場所は **持ち方・手の形を作る → 用途「煙管を持つ」→ 手首の補正** です。[手首のひねりを調整する](./wrist.mdx)では、補正OFF・手首だけ・前腕へ50％分散を同じ画角で見比べ、保存からVRでの切り替えまでを確認できます。

## 動作と確認範囲

煙管と箱を同じ手で持つ場面は煙管の形を優先し、口にくわえたらケース／箱の形へ切り替わります。
収納、火種を載せる、マッチの消去、Resetなどで対象の道具がなくなると元のジェスチャーへ戻ります。
指の形の機能はFistなどの操作入力値を書き換えず、追加の同期パラメーターを使いません。任意の手首補正は別に1 bit使用します。

Indexなどで指トラッキングを使う場合も、所作用の手の形が有効な間は、その手の指をアニメーション制御へ切り替えます。手首・腕は通常どおり追従します。所作が終了したら、その手の指をトラッキングへ戻します。未設定の用途や反対側の手は固定しません。
この対応を既に導入したアバターへ反映するには **アバターの導入を更新** を実行し、Sceneを保存して再アップロードしてください。
他のギミックも同じ指のTracking Controlを操作する場合は、互いの切替が競合する可能性があります。元の制御モードを取得して復元する機能ではなく、解除時はTrackingへ戻す方式です。

現在は一定の手の形を作る機能です。複数キーフレームの時系列アニメーション編集には対応していません。
Indexなどの指トラッキング、他のGesture上書き、アバター固有の可動範囲は実VRで確認してください。
Unity／NDMF／GestureManagerでの検査と、HMDでの持ちやすさ・全アバターとの互換性は別の確認です。
