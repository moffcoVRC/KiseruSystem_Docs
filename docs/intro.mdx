# 煙管システムについて

煙管システムを導入すると、VRChatのアバターで煙草を詰め、マッチで火をつけて煙管を吸えます。ここでは、必要な準備と操作の流れを紹介します。

## 導入の流れ {#まずは手元の支度から}

[画面を見ながら導入する](./editor-guide.mdx)では、アバターの配置セットアップを例に、煙管を動かすところから指の調整、導入までを順にたどれます。

すでに導入済みの方は、[VRでの煙管の使い方](./ritual.md)から操作を確認できます。衣装違いのアバターに同じ持ち方を引き継ぐ場合は、[衣装用プリセット](./presets.md)をご覧ください。

更新する方は[パッケージの更新手順](./install.md#update)、取り出せない場合は[ON後の取り出し確認](./help.md#retrieval)をご覧ください。

## 対応環境と操作方法 {#この手引きが扱うもの}

この説明書は **煙管システム 1.01** を対象にしています。VRChatのWindows PCアバターで、PCVRまたはデスクトップから使用できます。

デスクトップなど手を使わない環境では、[今すぐ一服](./instant-smoking.md)から、所作を省略して自動で吸うこともできます。

右手持ち・左手持ちを導入時に選べます。所作の説明は右手持ちを基準にしているため、左手持ちでは左右を読み替えてください。

:::note Questコントローラーの表示について
配置画面のQuest 3などの表示は、PCVRでの持ち方を考えるためのプレビューです。Quest単体版への対応を示すものではありません。
:::

## 道具の呼び名

| 呼び名 | この手引きでの意味 |
| --- | --- |
| 吸い口 | 煙管の口にくわえる側 |
| 火皿 | 煙草を載せ、火を入れる部分 |
| 煙草入れ | 煙管と一緒に取り出すケース |
| 煙草玉（火種） | 指先で取り出して火皿に載せる煙草。配置画面では「指の火種」「火皿の火種」と表記します |
| 懐の判定 | 道具を取り出したり、仕舞ったりする胸元の接触判定 |
| 持ち手 | 導入時に選んだ、煙管を持つ側の手 |
